# 终末地产线规划器 · src 更新包

以 endfield-planner-main.zip 的拆分结构为基础，已使用工艺筛选修订版Excel更新调度券产物，并保留非调度券全物品计算。

## 安装

将压缩包中的 index.html 和整个 src/ 同时覆盖到仓库根目录；保留 src/vendor/，它是 Excel/PDF 导入的本地依赖。无需编译。GitHub Pages 更新后刷新浏览器；旧缓存可使用 Ctrl+F5 清除。此版本使用独立 Worker 和本地模块，建议通过 GitHub Pages 或本地 HTTP 服务访问，不建议双击 file:// 页面。

## 本次修改

- 回顶部：右下角；只在离开页面顶部后显示。
- 计算浮动按钮：左上角；计算当前模式。自由模式固定计划改变后先核算第一步，第一步返回核算结果后计算第二步。计算中按钮暂时禁用。
- 自由模式：两组各默认两行，支持添加、删除；删除固定行需重新核算。
- 每个物料、反应气、激活入口均有单独折叠项；支持一键全部展开/收起。
- 求解结果复核变量、资源与整数约束；不再将负净耗气当成天然取用，也不以多余转气作为资源节约。相对期望价值的负差额是正常的比较值。
- 新版 Excel/PDF 附有恢复数据。导入后把上次最终产率及具体已选工艺作为固定计划，重新核算共享激活、占用和供电，再打开第二步。自动选工艺/共享设备可能因重新计算变化，最终资源以新计算为准。不要删去PDF最后的“续算恢复数据”页。
- 旧版 Excel 在包含完整资源参数和产率表时可尝试恢复；旧 PDF、扫描图片PDF、任意第三方文件没有恢复数据时拒绝猜测。旧版报告缺少参数时也会拒绝恢复。
- 导入文件在浏览器本地解析，不上传。最多25MB、PDF最多150页。
- “下载网站ZIP”会打包页面和依赖文件，避免只保存一个HTML导致脚本缺失。

## 算法与落地范围

主产率目标、优先级和固定/最低要求沿用现有模型。离散占用按整组，工程选项激活不可折算，连续选项激活可折算。有限搜索达到限制时报告为候选，不声称全局最优。物料与管道器具合计预算，不能回仓的管道余流若没有完整去向会提示未实现；不能把理论可行当成全部已落地。

## 新Excel与工艺权限更新


调度券工艺表与常规产线

调度券产物统一使用《基建配料表(20261004-010151).xlsx》的21行工艺数据，不再从全物品配方中扩展售卖路线。中电、古法重息壤的有节点／无节点两行是同一工艺的废液供给情况，求解时合并处理；外部废液在整个方案中只分配一次。非调度券产物仍保留原来的全物品配方计算方式，不因筛选售卖表删除其生产方法。

工艺显示为“表中工艺名：关键流程”，不包含修订细节。

常规产线指最容易落地、也是目前蓝图中最常见的生产方式。“只允许常规产线”排除赫铜、灼铜的液气2和液气3，其余调度券工艺允许；“允许非常规产线”额外开放这四条路线。非调度券全物品计算保留原规则，息壤转气选项独立。

赫铜原液气行修正为27总息壤（15反应＋12激活液）、6总气；灼铜原液气2修正为12总息壤（激活液）、36总气（30反应＋6激活）。重息壤原液气行87息壤中已包含内部自产60气成本，不再重复扣60气。三条新增路线均参与允许非常规时的自动工艺选择。所有灼铜路线共享酸性环境占用。连续解激活按负荷折算，工程／整数解按启用设备供给；占用仍按整组计算。

自由模式第一步即使不可行或价值未达到期望也可进入第二步；第二步重算固定与新增产物共同占用、资源及价值，显示最新期望差额。此改动不解除固定产率和资源约束。


数据：src/sales-recipes.js；原Excel：src/data/基建配料表(20261004-010151).xlsx。21行均展示，中电与古法重息壤的节点行通过同一工艺的全局废液变量计算，因此求解使用19条售卖工艺。不增加非调度券物品的价值。

本次界面更新：移除GPT登录；常规产线解释为最容易落地且当前蓝图最常见的方式，现按新表排除赫铜和灼铜的液气2、液气3。结果产物详情新增实际生产流程；自由模式新增流程搜索，点击候选确定工艺；名称与流程支持拼音首字母筛选（zt、zxr），配方目录同样支持。新增src/search.js，部署时必须一并覆盖src。
