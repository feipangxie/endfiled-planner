## 逐步配平与连续灼铜占用更新

- 点击产物：按实际产率逐步列出原料、产物、副产物、设备负荷和另需激活入口；来自原始单步配方。清水、污水、沉积酸、植物辅料不省略。分离芯及废液回收支路完整展开。步骤表不是重复添加的资源账；共享激活、环境与外部运输以主报告为准。
- 移除意见反馈入口、弹窗和脚本。
- 古法重息壤：30×ceil(产率/6)，5/min占用30、7/min占用60。
- 灼铜连续解：n为全部工艺合计等价满速，n=4k+t，0≤t<4；占用=acidCost×[k+min(t,1)]。0.5满速0.6，1—4满速1.2，4.5满速1.8，5—8满速2.4。整数／工程解保留整组计法。
- 复核案例：60固气重息壤＋6中电、12废液、液气转气，灼铜液气3为最佳。新占用规则下3.558139535/min，占用0.711627907息壤/min；占用设0时3.642857143/min。旧算法整组占用下为3.5/min。物料瓶颈是息壤等价容量，不是赤铜；自动工艺也不能超过上述上限。

## 私人定制模式与逐工艺权限（本次更新）


### 逐条工艺开关与私人定制模式

第二项工艺范围已改为全部调度券产物的逐条工艺列表。亮色开启、灰蓝暗色关闭，点击切换；默认关闭赫铜和灼铜的液气2、液气3。工程／极限预设不覆盖手动工艺开关。结果只使用开启且商品／活动权限允许的工艺。非调度券物品继续使用全物品配方。

私人定制模式包含五步：确认左侧输入；勾选尽量节省的基础资源；选择调度券生产态度；填写各调度券商品的权重和精细产率；填写非调度券商品优先级。上一／下一步保留全部答案。0权重表示未指定，可多项为0；重复的正数权重会将后填项归0并提醒。精细最低／固定产率是售卖产率，供电另补；不生产调度券时仍补足供电。紫晶矿在当前武陵模型不参与优化。

理论最高兑换值为(30000＋22800＋24000)×2＝153600价值/h；期望兑换使用左侧输入。一周库存按168小时计算，最低新生产价值/h＝max(0，期望×168－库存总售价)/168；每种默认50000个，活动权限关闭时不计活动库存。按总价值估算，不能保证具体收购种类和配额下一周内逐种售完。

所有固定产率、最低产率和兑换要求同时保护。全部生产选项优先最大化调度券总价值；其余生产态度先取满足兑换需求的最小调度券价值，为其他需求留资源。之后按第五步顺序最大化非调度券产物，再按第四步正数权重从大到小最大化调度券产物；精细最大化项即使权重0也参与。最后按勾选资源的容量比例之和尽量节省，再减少整体资源消耗。固定项不再最大化；未勾精细且权重0只参与兑换总值分配。整数解要求满速整线；工程候选要求有限取货模块与整数激活；连续解仍保留古法重息壤阶梯占用和灼铜分段占用。

导出问卷为JSON，包含五个答案和左侧输入；导入恢复后直接进入第五步，点击计算即可，也可返回修改。无方案会留在第五步保留数据。连续三次不同输入的计算未找到整数／工程方案，会自动改为连续解重算，提示计算机搜索时间复杂度较高；重复提交同一输入不累计。连续解也无方案时仍提示调整真实约束，不宣称原问题必定无解。候选搜索未完成时不会宣称全局最优。

问卷JSON仅在本地读取，不上传。下载包保持index.html、README.md、src三项完整结构。

## 倒灌大师 · 2026-10-07更新

### 倒灌大师（模式4）

目标为补齐4种瓶子各12种内容、赤铜耐压罐9种内容，共57种库存，默认每种90000个。空瓶／空罐各自也属于目标。填写现有数量后只补差额；既有非空成品不拆装，也不作为调度券收入。空容器可用于罐装，耐压罐还可用于分离芯，消耗记入同一库存账，最终仍须补齐。阶段内库存按净流量变化，起终库存均不为负；不借用未来库存。

蓝铁瓶30/min消耗60蓝铁；钢质瓶30/min消耗120蓝铁；赤铜瓶与赤铜耐压罐30/min消耗60赤铜。赫铜瓶对应五条赫铜工艺，每满速30瓶使用对应赫铜满速线2倍资源和激活，继承左侧赫铜工艺开关。售卖商品仍按当前筛选表，内容物按全物品单步配方计算。

免费内容：清水、沉积酸、芽针溶液、锦草溶液、污水；惰气按免费供给。息壤液与液化息壤按1:1；重息壤液按重息壤1:1。赤铜粉末＋沉积酸→赤铜液1:1，4赤铜液→1赫铜液；同时允许已提供的气液转换支路。1息壤液＋1污水同时产出1壤晶废液和1惰性壤晶废液，4惰性废液可回收1壤晶废液。这两种废液不重复扣资源，可以共享供应电池、古法重息壤与罐装。外部废液按左侧数量全局分配一次。

重息壤气可由提纯或转换支路供给；赤铜气、赫铜气和灼铜气按实际单步配方自动选择。灼铜气反应为2赫铜气＋1息壤气→1灼铜气；水蒸气与酸气虽然主料免费，转气激活液化息壤仍须计成本。所有激活和环境共享以阶段资源账为准，单步表不另行加到总消耗。

每台灌装机每分钟30个，同一阶段同时制作不同非空成品需独立机台。灌装机上限默认64台，可在模式4填写；资源流量连续、灌装机台数为整数，古法阶梯与灼铜分段占用保留。左侧整数／工程解选项在本模式不沿用，页面会明确提示；其余基础资源、外运、期望额度、废液、供电与售卖工艺权限沿用。

并行优先为共同完工的连续流量最短时间候选，并显示放松整数机台／占用后的时间下界；候选与下界的差距不等于已证明全局最优。分批为一次罐装一种容器，机台不足时把内容物分组；比较三种容器顺序，选择其中耗时最短的可行候选。各阶段分别复核资源上限、库存不为负和扣供电后的调度券产值≥左侧期望，不以跨阶段平均值替代。换线、首件反应延迟、场地、普通设备总数及水／惰气设施上限不建模；实际建造需要核对。
